# Web Card Matching Game

A browser-based card matching game developed with HTML, CSS, and vanilla JavaScript.

This was created as a five-person graduation project. Aaron Lin served as the team leader and participated in task coordination, feature integration, and debugging.

## Features

- 30-card game board with 13 matching pairs and 4 bomb cards
- 60-second countdown timer
- Time bonuses and penalties
- Falling clover bonus items
- Three one-time special abilities
- Tutorial modal and responsive mobile layout

## Technologies

- HTML5
- CSS3
- JavaScript

## Run locally

Open `index.html` in a browser. No package installation or build step is required.

## GitHub Pages

1. Upload all files in this repository to GitHub.
2. Open the repository's **Settings**.
3. Select **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
